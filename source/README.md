# rezaxr14.github.io

Personal portfolio website of Reza Nadimi — AI/ML Engineer.

Live site: https://rezaxr14.github.io

## Structure

- `source/` — the full React project (create-react-app). All site content lives in `source/src/portfolio.js`.
- Repo root (when deployed) — the production build output that GitHub Pages serves.

## Run locally

```bash
cd source
npm install
npm start
```

Open http://localhost:3000

## Build

```bash
cd source
npm run build
```

The production site is emitted to `source/build/`.
